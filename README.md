## 关于隐私的一点提醒

网页会被搜索引擎收录、任何人都能访问，和你私下发给招聘方的 PDF 简历不是一回事。我**没有**把你的手机号和微信号放进网页（简历 PDF 里有，但那是点对点发送的），公开页面只留了邮箱。如果你确实想公开手机/微信，告诉我，我再加上。

## 发布到 GitHub Pages

1. 在 GitHub 建一个新仓库（比如 `yibozuo.github.io`，用你自己的 GitHub 用户名，这样部署后网址就是 `https://你的用户名.github.io/`；也可以用普通仓库名，网址会带仓库名后缀）。
2. 把 `2_个人网页` 目录下的所有文件（`index.html`、`assets/` 整个文件夹、这份 `README.md`）推到仓库根目录。
3. 仓库 Settings → Pages → Source 选 `main` 分支 / `/ (root)`，保存。
4. 等一两分钟，网址就能访问了。

需要的话，我可以帮你写好推送到 GitHub 的 git 命令（需要你已经建好仓库、本机配置好 git 和 GitHub 登录）。
